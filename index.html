GeoDispatch: Dynamic KD-Tree Spatial Engine

GitHub

A C++17 Dynamic KD-Tree engine for real-time dispatch of moving 2D coordinates.

  • Added AVL-based subtree rebuilding so search stays fast during heavy insertions.
  • Combined Dijkstra's algorithm with lazy rebuilding for an average query latency of 600 µs.
  • Built a Node.js gateway with 10–60 RPM rate limiting, idempotency caching and subprocess I/O.
  • Ran the system as isolated services with Docker Compose, using PostgreSQL/PostGIS for storage and Redis for caching.
